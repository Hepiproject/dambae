# 담배 한 대 · dambae

> 비흡연자를 위한 온라인 흡연 사이트

브라우저에서 담배 한 대를 피우는 감성 인터랙션. 전부 캔버스·Web Audio로 합성된 자기완결형 단일 페이지(외부 요청 0).

**라이브:** https://dambae.vercel.app

## 조작
- **아래로 긁어내리기**(마우스 드래그 / 터치 스와이프) → 라이터로 담뱃불 붙이기
- **꾹 눌러 빨고 · 떼면 연기** (누른 시간만큼 길게)
- **우클릭 / 더블탭** → 재떨이에 재 털기 (안 털면 저절로 떨어짐)
- 다 피우면 꽁초가 재떨이로 던져지고 새 담배가 물림
- 담배 선택: 에쎄 / 마쎄 / 말보로 / 시가
- 날씨: 밤 · 낮(여름) · 비 · 눈 — 각 날씨별 배경음(풀벌레·바람 / 운동장 웅성거림·경적 / 빗소리 / 눈 밟는 소리)

## 구조
- `cigarette.html` — 개발 소스(작업용, 디버그 훅 포함)
- `build.js` — 배포 빌드(죽은 코드·디버그 제거 + HTML 문서 래핑)
- `index.html` — 빌드 산출물(Vercel이 서빙)
- `og.png` — 공유 썸네일(1200×630)

## 빌드 & 배포
```bash
node build.js          # cigarette.html → index.html
npx vercel deploy --prod
```
GitHub 연동 시 push → Vercel 자동 배포.

## 스택
순수 HTML/Canvas/Web Audio. 빌드 의존성 없음(node는 빌드 스크립트 실행용).
